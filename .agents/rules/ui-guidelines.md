# Directives d'interface utilisateur (UI Guidelines)

- **Politique sur les icônes** : Ne jamais insérer d'icônes (balises FontAwesome `<i class="...">`, émojis ou icônes décoratives) devant ou dans les éléments d'interface (menus, boutons, titres, labels, options de configuration) SAUF si l'utilisateur le demande explicitement. Privilégier une interface sobre, lisible et textuelle.

- **Politique de tests** : lance pas de serveurs de tests. travaille uniquement en analysant la codebase. liste moi ensuite les actions à faire pour que je valide les développements
